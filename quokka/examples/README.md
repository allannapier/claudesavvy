# Quokka examples

`sample.html` is a real Quokka run against this repository's harness on the
machine that committed it. Open it directly in a browser, or preview it
through GitHub via:

<https://htmlpreview.github.io/?https://raw.githubusercontent.com/allannapier/claudesavvy/claude/agent-harness-viewer-SYxCo/quokka/examples/sample.html>

To regenerate it after changes:

```bash
pip install -e quokka
quokka --repo . --out quokka/examples/sample.html
```
